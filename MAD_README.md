# MAD Assistant

Personal JARVIS-style AI assistant for Sushil Sheokand.
Business: RAJAT ELECTRO-MECH SOLUTIONS (REMS), Uchana, Haryana.

Features: Natural Hindi/Haryanvi AI voice conversation, background voice service,
floating button, notification controls, Gemini/OpenAI provider choice with own API keys,
personal memory and context, voice Khata Book with customer identification,
customer management, work material estimation with fitting stages,
dynamic items/categories/units, personal tasks and reminders, shop-wise
shopping lists, PDF generation, backup and restore, JARVIS-style UI with female Hindi voice.

Package: com.sushil.madassistant (independent from the old REMS Business app)

Build: GitHub Actions builds the APK automatically on every push.
Download it from the Actions tab (latest run > Artifacts).
